# SpaceX Falcon 9 Landing Prediction

This project analyzes SpaceX Falcon 9 launch data to predict successful first-stage landings.

## Project Objectives
- Collect SpaceX launch data
- Clean and analyze the data
- Create charts and visualizations
- Analyze launch data using SQL
- Build interactive maps and dashboards
- Predict landing success using machine learning
